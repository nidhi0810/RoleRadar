# RoleRadar

RoleRadar is a job discovery platform that helps users find and manage job opportunities based on their preferences.

## Features

* Search and browse job opportunities
* Match jobs based on **role, skills, location, experience, and salary**
* Add and manage job postings
* Track job applications
* Upload resumes
* Store resumes using **AWS S3**
* Receive and process job postings from **WhatsApp**
* Extract multiple job postings from a single message
* User authentication

## Tech Stack

**Frontend:** React, JavaScript, HTML, CSS

**Backend:** Node.js, Express.js

**Database:** MongoDB

**Other:** AWS S3, WhatsApp integration, LLM API

## Getting Started

```bash
git clone <repository-url>
cd RoleRadar
npm install
npm start
```

Create a `.env` file with the required database, AWS, authentication, and API credentials.
